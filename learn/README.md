# 从零写出 pi：一门 coding agent 课程

这门课带一个**完全没有编程基础**的人，一步一步写出一个真正能用的 coding agent——**mini-pi**。它的架构和本仓库里的 [pi](../README.md) 一模一样，只是去掉了大量"锦上添花"的功能，让每一行代码你都能亲手写出来、完全看懂。

课程的最终目标不是"跟着敲完一遍"，而是：**合上教程、不借助任何 AI，你能自己从一个空目录写出一个 coding agent，并且能读懂、修改真正的 pi。**

## 最终成果

学完全部里程碑后，你会得到一个这样的程序：

```
$ mini-pi

 > 给 src/utils.ts 里的 formatDate 函数加上单元测试，然后运行测试

 我先看一下这个函数的实现。

 read src/utils.ts
 │ export function formatDate(date: Date): string {
 │   ...（共 42 行）

 write test/utils.test.ts
 │ 已写入 31 行

 $ node --test test/utils.test.ts
 │ # tests 4
 │ # pass 4

 测试已添加并全部通过：覆盖了普通日期、闰年、月末和非法输入四种情况。

 ─────────────────────────────────────────────────────────────
 > 
 ─────────────────────────────────────────────────────────────
 ~/projects/todo-app · deepseek-chat · ↑12.3k ↓1.1k · $0.003 · 上下文 9%
```

它能：

- 和多家大模型对话（DeepSeek、通义千问、Kimi、智谱、OpenAI、Anthropic、本地 Ollama……），流式显示回答
- 自己调用工具：读文件、写文件、精确修改代码、执行命令
- 读取项目里的 `AGENTS.md`，遵守项目规则
- 保存会话，下次继续；对话太长时自动压缩上下文
- 在终端里提供流畅、不闪烁的交互界面，支持中文输入法，按 Esc 随时打断
- 不联网、不花钱也能运行和测试（课程提供假模型服务器）

整个 mini-pi 大约 5000 行 TypeScript，**零第三方运行时依赖**：HTTP 通信、流式解析、参数校验、终端界面全部亲手实现。

## 怎么学

### 每个里程碑的结构

每个里程碑目录里有：

- `README.md`：正文。按"问题 → 例子 → 解决办法"的顺序讲解，然后带你一步步实现。
- `code/`：参考答案——完成这个里程碑后，你的项目**应该长什么样**。从里程碑 06 开始，它是一个完整的 mini-pi 项目，可以直接运行和测试。
- `exercises/` 和 `solutions/`（部分里程碑有）：练习和参考答案，练习自带检查。

正文里通常有这些小节：

| 小节 | 作用 |
| --- | --- |
| 你将学到 | 本章的知识点清单 |
| 概念讲解 | 为什么需要它、它是怎么工作的 |
| 动手实现 | 一步步写代码 |
| 运行与验证 | 怎么确认你写对了 |
| 接口约定与测试 | 文件名、函数签名，以及怎么用参考测试检查**你自己的代码** |
| 常见错误 | 新手最容易踩的坑 |
| 练习 / 自测问题 | 巩固和检验理解 |
| 对照 pi 源码 | pi 里对应的代码在哪里、多做了什么、为什么 |
| 闭卷挑战 | 不看资料重写本章核心代码 |

### 推荐的学习方法："三遍法"

1. **第一遍：跟着敲。** 读正文，把代码一个字一个字敲进你自己的项目。**不要复制粘贴**——敲的过程会逼你注意每一个细节。运行，确认结果正确。
2. **第二遍：看着目录写。** 删掉（或新建一个分支），只看正文的小标题和"接口约定"，自己写出来。卡住了再看参考答案。
3. **第三遍：闭卷。** 完成每章最后的"闭卷挑战"。

### 遇到问题怎么办（不用 AI）

1. **读报错信息**：错误类型、错误消息、文件名和行号。里程碑 00 第 8 节教你怎么读。
2. **打印**：在怀疑的地方 `console.log`，看变量的实际值和你以为的是否一样。
3. **缩小范围**：注释掉一半代码，看问题还在不在。
4. **对照参考答案**：用 `diff` 或 VS Code 的对比功能，比较你的文件和 `code/` 里的同名文件。
5. **查文档**：MDN、Node.js 文档、大模型服务商的 API 文档。
6. **看[常见问题](TROUBLESHOOTING.md)。**

### 你的项目

整门课你只维护**一个**项目：`~/my-pi`（里程碑 00 创建）。

- 里程碑 00~05 的练习脚本放在 `my-pi/playground/`。
- 从里程碑 06 开始，正式代码放在 `my-pi/src/`，测试放在 `my-pi/test/`。

每完成一个里程碑就 `git commit` 一次。这样你随时可以回看自己是怎么一步步走过来的。

## 运行环境

- Node.js **22.18 或更高**（推荐 24 LTS）。Node 可以直接运行 `.ts` 文件，不需要任何编译步骤。
- macOS、Linux，或 Windows 上的 WSL2。
- 一个大模型 API key（可选，见下文）。

### 不花钱也能学：假模型服务器

课程提供了一个[假模型服务器](tools/fake-llm/README.md)，它会假装自己是 OpenAI / Anthropic 的服务。复读你的话、按简单规则调用工具、或者按剧本回复。**所有里程碑都可以只用它完成**，测试也全部基于它。

```bash
node learn/tools/fake-llm/server.ts
```

### 接入真正的大模型

真正的大模型当然更有意思。里程碑 03 会详细介绍怎么获取 API key。国内用户可以选择 DeepSeek、通义千问、Kimi、智谱等，它们都兼容 OpenAI 的接口格式，价格便宜；也可以在自己电脑上用 Ollama 运行开源模型，完全免费。

## mini-pi 和 pi 的对应关系

| mini-pi | pi | 作用 |
| --- | --- | --- |
| `src/ai/` | [packages/ai](../packages/ai) | 统一的大模型接口：消息类型、流式事件、各家服务商适配 |
| `src/agent/` | [packages/agent](../packages/agent) | Agent Loop、Agent 类、工具执行 |
| `src/tools/`、`src/core/`、`src/modes/` | [packages/coding-agent](../packages/coding-agent) | 编程工具、系统提示词、会话、压缩、命令行和交互模式 |
| `src/tui/` | [packages/tui](../packages/tui) | 终端界面框架：差分渲染、输入框、Markdown |

mini-pi 刻意省略了 pi 的这些部分（里程碑 20 会带你去读）：扩展系统、技能（skills）、提示词模板、主题、图片、OAuth 登录、几十家服务商的兼容细节、RPC 模式、SDK、会话树导航界面等。
